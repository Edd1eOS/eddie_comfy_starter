# 启动器界面规范

## 目标

启动器负责把 ComfyUI 的安装、文件和运行状态解释清楚，不复制节点编辑器，也不把底层参数直接堆到首页。

## 首页

隐藏系统标题栏，顶部品牌区保留原生拖动、双击最大化和边缘缩放，右侧提供最小化、最大化/还原、关闭按钮。环境已安装且服务未启动时显示「点击下面的按钮打开webui」和「本地离线运行的工作站，已完成环境配置和依赖打包」；未安装时仍显示安装提示，避免误报准备完成。

主启动器采用浅绿色主题：薄荷绿与嫩绿色的柔边圆形背景透过半透明卡片，配白色细描边、轻阴影、28–32px 卡片圆角和胶囊按钮，模拟玻璃层次；不启用桌面透视。模糊只应用于不接收点击的背景装饰，正文和按钮保持清晰。保留原有控件名称、文案、操作和状态逻辑，并提供悬停、按下及键盘焦点反馈。

首页只保留以下入口：

1. **准备工作台 / 打开创作界面**：同一个主按钮，根据当前状态显示下一步。
2. **停止运行**：只停止本工作台启动的 ComfyUI 服务。
3. **模型与素材**：打开模型目录。
4. **工作流**：打开工作流目录。
5. **输出管理**：打开生成结果目录。
6. **检查问题**：检查显卡、磁盘、运行环境和端口。
7. **更改存储位置**：选择模型、工作流和输出文件的保存位置。

运行日志默认折叠。安装版本、监听地址、Python 路径等技术信息不占用首页主要空间。

## 名词解释

「模型与素材」提供「模型路径设置」：六种模型类别均可引用多个外部目录，显示用途和本机默认目录。保存到当前数据位置的 `state/model-paths.json`，启动时生成 JSON 格式的 YAML，通过 `--extra-model-paths-config` 交给 ComfyUI。配置只增加搜索目录，不移动模型、不更改默认下载目录、不允许添加 Custom Node 搜索路径；移除最后一个引用后启动不再传入外部配置。保存不会中断现有任务，用户在任务结束后重启服务并刷新 WebUI 生效。

- **ComfyUI**：用节点连接图片或视频生成步骤的创作界面。
- **工作流**：保存好的一套生成步骤，可以重复运行和修改。
- **Checkpoint**：决定基础生成能力和风格的主模型。
- **LoRA**：为主模型增加角色、画风或细节的小型附加模型。
- **VAE**：把模型内部结果转换为最终颜色和图像的解码组件。
- **Custom Node**：为工作流增加新步骤的第三方扩展；安装它等于运行第三方代码。

专业名词第一次出现时必须同时显示一句用途说明。按钮使用用户目标命名，例如“打开创作界面”，不使用 `start server`、`runtime` 或 `daemon`。

## 分层

- 启动器：准备环境、选择目录、启动、停止、检查问题和管理入口。
- ComfyUI Web：编辑节点、运行工作流、查看队列和预览结果。
- 后续简化模式：把精选工作流转换为表单，普通用户无需直接编辑节点。
