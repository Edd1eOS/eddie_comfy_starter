# 启动器界面规范

## 目标

启动器负责把 ComfyUI 的安装、文件和运行状态解释清楚，不复制节点编辑器，也不把底层参数直接堆到首页。

## 首页

首页只保留以下入口：

1. **准备工作台 / 打开创作界面**：同一个主按钮，根据当前状态显示下一步。
2. **停止运行**：只停止本工作台启动的 ComfyUI 服务。
3. **模型与素材**：打开模型目录。
4. **工作流**：打开工作流目录。
5. **输出管理**：打开生成结果目录。
6. **检查问题**：检查显卡、磁盘、运行环境和端口。
7. **更改存储位置**：选择模型、工作流和输出文件的保存位置。

运行日志默认折叠。安装版本、监听地址、Python 路径等技术信息不占用首页主要空间。

## 名词解释

- **ComfyUI**：用节点连接图片或视频生成步骤的创作界面。
- **工作流**：保存好的一套生成步骤，可以重复运行和修改。
- **Checkpoint**：决定基础生成能力和风格的主模型。
- **LoRA**：为主模型增加角色、画风或细节的小型附加模型。
- **VAE**：把模型内部结果转换为最终颜色和图像的解码组件。
- **Custom Node**：为工作流增加新步骤的第三方扩展；安装它等于运行第三方代码。

专业名词第一次出现时必须同时显示一句用途说明。按钮使用用户目标命名，例如“打开创作界面”，不使用 `start server`、`runtime` 或 `daemon`。

## 分层

- 启动器：准备环境、选择目录、启动、停止、检查问题和管理入口。
- ComfyUI Web：编辑节点、运行工作流、查看队列和预览结果。
- 后续简化模式：把精选工作流转换为表单，普通用户无需直接编辑节点。
